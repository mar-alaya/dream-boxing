# 🥊 Dream Boxing

**Dream Boxing** is a web development project created with **HTML5**, **CSS3** and **JavaScript** as part of the **Software Development course at the Digital Career Institute (DCI)**.

The goal of this project was to build a visually engaging website about boxing while applying the fundamental concepts of semantic HTML, CSS styling and my first basic interaction with **DOM manipulation** using JavaScript.

## Project Overview

Dream Boxing is a fictional boxing website designed especially for people who are new to the sport.

The website provides an introduction to boxing fundamentals, including basic techniques, weight classes, famous boxing legends and the main rules of the sport.

I chose boxing as the topic because I have been practicing the sport myself for the past three years and it has become one of my passions. I wanted to create a project around something I genuinely enjoy and that I can personally relate to.

## Development Process

This project was developed following the typical stages of a web design workflow:

- Research and concept development
- Wireframing and content planning
- HTML structure using semantic elements
- CSS styling and layout development
- Introduction to JavaScript and DOM manipulation
- Testing and optimization

## Features

- Semantic HTML5
- CSS3 with Flexbox
- Internal navigation
- Functional contact form
- Hover effects and interactive elements
- Basic JavaScript interactions using DOM manipulation

## Technologies

- HTML5
- CSS3
- JavaScript

## What I Learned

During this project I learned how to:

- Structure a website using semantic HTML.
- Create layouts using CSS Flexbox.
- Organize content, images and other assets in a real project.
- Design a website around a specific visual concept.
- Improve user experience through navigation and clear content structure.
- Work with JavaScript for the first time and understand the basics of **DOM manipulation** and interact with HTML elements using JavaScript.
